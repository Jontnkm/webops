웹사이트 품질 검사

홈페이지 주소를 넣으면 깨진 링크·이미지, 화면 동작 오류, 휴대폰 화면 깨짐, 장애인·고령자 이용 편의(접근성)까지 한 번에 검사합니다.

www.로 시작하는 주소만 넣어도 됩니다.

점검 종류 종합점검 외에는 웹사이트 전체 페이지(최대 300페이지)를 점검 · 로딩속도·SEO 점검은 페이지마다 10~60초 더 걸림

종합점검 웹사이트를 선택한 범위에 맞게 종합점검합니다.

점검 항목 웹사이트 전체 페이지(최대 300페이지)

1페이지 접속 · 깨진 링크열리지 않거나 오류(404·500 등)가 나는 페이지와 링크
2깨진 이미지 · 파일보이지 않는 그림, 불러오지 못한 글꼴·스타일·스크립트 파일
3데이터 · 스크립트 오류화면에 쓸 데이터 요청 실패, 화면 동작을 막는 스크립트 오류

점검 항목 전체 페이지 · 자동 검사라 인증 심사 판정과 다를 수 있음

1그림 설명 · 글자 대비그림의 대체 텍스트, 글자색과 배경색 대비(4.5:1 이상)
2이름표 · 문서 구조입력칸·버튼·링크의 이름, 제목·표 구조, 페이지 언어
3KWCAG 2.2 검사항목표33개 항목별 결과, 직접 확인할 항목 안내 · 접근성 보고서 PDF

점검 항목 전체 페이지 · Lighthouse 기준 · 페이지마다 10~60초 더 걸림

1첫 화면이 뜨는 속도첫 내용이 보이기까지, 가장 큰 내용이 다 보이기까지 걸린 시간
2반응 · 화면 밀림눌러도 반응이 늦어지는 시간, 읽는 중 화면이 밀리는 정도
3페이지별 속도 점수모든 페이지 0~100점, 느린 원인과 개선 방안

점검 항목 전체 페이지 · Lighthouse 기준 · 페이지마다 10~60초 더 걸림

1제목 · 설명 문구페이지 제목, 검색 결과에 나오는 설명 문구
2검색 로봇 접근검색 차단 설정, robots.txt, 정상 응답 여부
3링크 · 그림 정보알아보기 쉬운 링크 문구, 그림 설명 · 페이지별 SEO 점수

점검 항목 전체 페이지 · 관리자 주소 찔러보기 같은 공격성 검사는 하지 않음

1https · 인증서암호화 접속(https), 인증서 만료·신뢰, http로 오면 https로 넘기는지
2보안 설정 (응답 헤더)HSTS, 클릭재킹 방지, 파일 형식 위장 방지, CSP, 서버 버전 노출
3쿠키 보호쿠키의 Secure · HttpOnly 설정 (가로채기·스크립트 탈취 방지)

점검 항목 전체 페이지 · 휴대폰 화면으로 열어 점검

1가로 밀림화면보다 넓은 요소 때문에 옆으로 밀리는지
2반응형 · 확대휴대폰 화면 설정(viewport)이 없는지, 손가락 확대를 막았는지
